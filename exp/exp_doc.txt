===========================
Implementation of ``exp()``
===========================

Steps to implement an exponent function.


Range reduction
===============

Like many floating point solvers, one only need focus on the significand, since
the exponent can often be solved quickly.

In floating point form, :math:`e^x = 2^k (1 + \alpha)` for some integer
:math:`k` and real :math:`\alpha`.  Floating point would normally require that
:math:`0 \le \alpha < 1`, but we don't yet need to apply this constraint.  The
relationship between :math:`x`, :math:`k`, and :math:`\alpha` is

.. math::

   x = k \log 2 + \log (1 + \alpha)

This can be simplified without loss of generality by defining :math:`r = \log
(1 + \alpha)`, so that :math:`x = k \log 2 + r`.  The equation then becomes

.. math::

   e^x = 2^k e^r.

If :math:`k` is known, then the problem is reduced to evaluating :math:`e^r`.
The simplest path is to assign a unique value of :math:`k` for a given
:math:`x`.

* :math:`0 \le \alpha < 1`

  If we interpret :math:`\alpha` as the floating point significand, then the
  floor operator offers a simple expression for :math:`k`, since
  
  .. math::

     \left\lfloor \frac{x}{\log 2} \right\rfloor
        &= k + \left\lfloor \frac{1 + \alpha}{\log 2} \right\rfloor \\
        &= k.

  This makes it simply to apply floating point analysis to the result, and
  avoids any rounding rule ambiguity, but the nonsymmetric range of :math:`r`
  can make it slightly more challenging to estimate :math:`e^r`.

* :math:`-\tfrac{1}{2} \log 2 \le r < \tfrac{1}{2} \log 2`

  Replacing the floor operator with a rounding operator produces a symmetric
  range for :math:`r`.

  .. math::

     \left[ \frac{x}{\log 2} \right] = k + \left[ \frac{r}{\log 2} \right]

  :math:`k` is unique if :math:`-\tfrac{1}{2} < \tfrac{r}{\log 2} <
  \tfrac{1}{2}`.  This produces a symmetric domain which can improve the
  estimation of :math:`e^r`.  But it also introduces ambiguities about
  rounding, including sensitivity to the floating point rounding model which
  may not be known.  Nonetheless, this seems to be the most common method.

Whatever one chooses, one ends up with a clear expression for :math:`k`, and
only needs to evaluate :math:`e^r` over a smaller domain with clear bounds.

Polynomial Approximation
========================

Next step is to approximate :math:`e^r` over the range of :math:`r`.  Herein,
:math:`k = \left[ \tfrac{x}{\log 2} \right]` and :math:`r \in
\left(-\tfrac{1}{2} \log 2, \tfrac{1}{2} \log 2 \right)`.

Many polynomial estimations are bad: Taylor series is based on a single point,
Pade approximants are too computationally expensive.  The common choice is the
*minimax polynomial*, built by the *Remez algorithm* from *Chebyshev nodes*.

Remez Algorithm
===============

This algorithm constructs the polynomial which minimizes the maximum
absolute difference (i.e. the :math:`\infty`-norm).  It is based on the
*equioscillation theorem*.

   If :math:`f` is a continuous function over :math:`[a,b]` and :math:`g` is a
   polynomial of degree :math:`n`, then :math:`g` minimizes the *uniform norm*
   :math:`\lVert f - g \rVert_\infty` if and only if there are
   :math:`n+2` points :math:`a \le x_0 < x_1 < \cdots < x_{n+1} \le b` such
   that :math:`f(x_i) - g(x_i) = \sigma (-1)^i \lVert f - g \rVert_\infty`
   where :math:`\sigma` is either :math:`+1` or :math:`-1`.

In other words, the optimal polynomial (in an :math:`\infty`-norm sense) is one
where the error oscillates between the maximum error.  Not going to prove it,
but this is the general idea.

* A polynomial of degree :math:`n` oscillates at most :math:`n` times.  Add two
  end points (which may or may not be :math:`a` and :math:`b`), and you get
  :math:`n+2` extrema from some desired curve.
  
* Any reduction of error in one extrema increases the error in the other
  extrema.  The only way to get a true minimum over all extrema is to equalize
  the error over these points.

We therefore seek a polynomial :math:`g(x)` with oscillating error :math:`\pm
E` at :math:`n+2` points :math:`x_i` from :math:`a` to :math:`b`.

.. math::

   a_0 + a_1 x_0 + a_2 x_0^2 + \ldots + a_n x_0^{n} + E &= f(x_0) \\
   a_0 + a_1 x_1 + a_2 x_1^2 + \ldots + a_n x_1^{n} - E &= f(x_1) \\
   a_0 + a_1 x_2 + a_2 x_2^2 + \ldots + a_n x_2^{n} + E &= f(x_2) \\
   a_0 + a_1 x_3 + a_2 x_3^2 + \ldots + a_n x_3^{n} - E &= f(x_3) \\
   \ldots \\
   a_0 + a_1 x_{n+1} + a_2 x_{n+1}^2 + \ldots + a_n x_{n+1}^{n} \pm E &= f(x_{n+1}) \\
